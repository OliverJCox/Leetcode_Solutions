# LeetCode Solutions

A collection of my solutions to **LeetCode[https://leetcode.com/]** problems, organised by topic and difficulty. I will add the different branches when required as I progress through the problems. I will also include a markdown file for each of the questions. 

The purpose of this repository is to document my problem-solving journey and improve my understanding of algorithms and data structures.

**Environment and language**

This repository contains solutions implemented primarily in **Python 3.14**, using **VSCode**. However I may solve some problems in other languages to improve my understanding of those languages.
